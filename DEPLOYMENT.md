# Analytico Deployment Guide

Deploy the React frontend to **Vercel** and the Flask API to **Render** (with Render PostgreSQL for users).

**Recommended for portfolio:** `ANALYTICS_MODE=mock` (realistic demo data, no social API approval needed).

---

## 1. Deploy Backend (Render)

1. Push this repo to GitHub.
2. Go to [render.com](https://render.com) → **New** → **Blueprint**.
3. Connect the repo — Render reads `render.yaml`.
4. Set these environment variables when prompted:

| Variable | Value |
|----------|-------|
| `DATABASE_URL` | Render PostgreSQL connection string (or leave unset for SQLite on ephemeral disk) |
| `CORS_ORIGINS` | `https://YOUR-VERCEL-APP.vercel.app` (update after frontend deploy) |
| `ANALYTICS_MODE` | `mock` |
| `SECRET_KEY` | Auto-generated by Render |
| `JWT_SECRET_KEY` | Auto-generated by Render |
| `FRONTEND_URL` | `https://YOUR-VERCEL-APP.vercel.app` |

5. Deploy. Note your API URL, e.g. `https://analytico-api.onrender.com`.
6. Verify: `curl https://analytico-api.onrender.com/health`

---

## 2. Deploy Frontend (Vercel)

1. Go to [vercel.com](https://vercel.com) → **Add New Project**.
2. Import the same GitHub repo.
3. Set **Root Directory** to `my-app`.
4. Framework preset: **Create React App** (auto-detected).
5. Add environment variable:

| Variable | Value |
|----------|-------|
| `REACT_APP_API_URL` | `https://analytico-api.onrender.com` |

6. Deploy. Note your URL, e.g. `https://analytico.vercel.app`.

---

## 3. Connect Frontend ↔ Backend

1. In **Render**, update `CORS_ORIGINS` and `FRONTEND_URL` to your Vercel URL:

```
CORS_ORIGINS=https://analytico.vercel.app,http://localhost:3000
FRONTEND_URL=https://analytico.vercel.app
```

2. Redeploy the Render service (or it may auto-redeploy on env change).
3. Test the live app: register → login → connect a Facebook Page → open the dashboard.

## Analytics: Mock vs Live

### Portfolio (recommended): `ANALYTICS_MODE=mock`

- The dashboard shows polished demo analytics.
- No Meta developer approval needed.
- Fully demoable in interviews.

### Optional live Facebook data: `ANALYTICS_MODE=live`

Requires a **Facebook Page** you manage and a Meta developer app.

1. Create an app at [developers.facebook.com](https://developers.facebook.com).
2. Add the **Facebook Login** product.
3. Register your callback URL (`https://analytico-api.onrender.com/api/auth/meta/callback`) as a valid OAuth redirect URI.
4. Set on Render:

```
ANALYTICS_MODE=live
FACEBOOK_APP_ID=<app id>
FACEBOOK_APP_SECRET=<app secret>
META_REDIRECT_URI=https://analytico-api.onrender.com/api/auth/meta/callback
```

Users then connect their Facebook Page via the in-app "Connect with Meta" flow, and the dashboard shows live Page data.

## Local Development

```bash
cp .env.example .env
python -m venv venv
source venv/bin/activate && pip install -r requirements.txt && python run.py
```

```bash
cd my-app && npm install && npm start
```

Users are stored in a local SQLite file (`analytico.db`) — no external database needed.

## Troubleshooting

| Issue | Fix |
|-------|-----|
| CORS error in browser | Add your Vercel URL to `CORS_ORIGINS` on Render |
| `401` on dashboards | Log in again; JWT may have expired |
| Render cold start (~30s) | Free tier sleeps; first request wakes it |
| OAuth redirect mismatch | `META_REDIRECT_URI` must exactly match the URI registered in your Facebook App |
| Blank page on Vercel refresh | `vercel.json` rewrites are already configured |
